▸ How do I get this? (one-time, ~10 min, free)
  1. Go to console.firebase.google.com → Add project (any name). Skip Analytics.
  2. Left menu → Build → Realtime Database → Create Database → start in locked mode.
  3. In the Rules tab, paste the rules from the note the app shows you and Publish.
  4. Left menu → Build → Authentication → Get started → Anonymous → Enable.
  5. Project settings (⚙︎) → Your apps → Web (</>) → register → copy the firebaseConfig block and paste it above.
  6. Do this once, then send the same file/URL to the other phone and just pick the other name.
